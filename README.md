Railway Reservation System Using Python

Project Overview

The Railway Reservation System is a Python-based project designed to understand and implement basic Python programming concepts through a railway ticket booking system.

This project demonstrates passenger information management, train details, ticket fare calculation, reservation status, and ticket confirmation using Python.

Objectives

* Understand Python variables and data types.
* Implement conditional statements and logical operators.
* Perform ticket fare and GST calculations.
* Manage passenger and train information.
* Understand basic railway reservation logic.

Technologies Used

* Programming Language: Python
* Platform: Jupyter Notebook
* File Format: IPYNB

Concepts Covered

This project covers the following Python concepts:

* Variables and Identifiers
* Data Types and Type Conversion
* Input and Output Functions
* Operators
* Conditional Statements (if, elif, else)
* Logical Operators (and, or, not)
* Loops
* Lists and Tuples
* Functions
* Basic Data Handling

Project Features

* Display train information
* Store passenger details
* Display ticket information
* Calculate ticket fare
* Calculate GST and final payable amount
* Check ticket confirmation status
* Manage waiting list and RAC status
* Apply senior citizen discount eligibility
* Display booking confirmation details
